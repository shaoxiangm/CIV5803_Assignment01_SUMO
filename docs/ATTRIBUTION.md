# Data attribution and scope

## OpenStreetMap-derived network

`network/george_town_core_v3.net.xml` is a derived SUMO network based on OpenStreetMap data and model-specific edits. OpenStreetMap data are © OpenStreetMap contributors and are available under the Open Database License (ODbL) 1.0. See https://www.openstreetmap.org/copyright and https://opendatacommons.org/licenses/odbl/1-0/.

## Omitted inputs

Certain course-provided or third-party source datasets are not redistributed in this repository. In particular, the route-demand input and calibration inputs are omitted pending confirmation of redistribution permission. The published CSV files are model-derived validation and comparative outputs, not source observations.
